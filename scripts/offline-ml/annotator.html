Guinea pig crop annotation

Draw one tight box around the entire visible guinea pig, including ears and feet. Use the same rule on every photo. Do not add a margin yourself.

Local only: 27 references + 9 development photos. No test images, uploads, or model predictions.

Square crop preview

The exporter adds a fixed 5% margin on each side of the longer box dimension. The animal is not stretched. Gray padding appears only beyond the photo edge. OpenCLIP will apply its usual resizing and normalization.
Coordinates use the original image pixels: (0,0) is top-left; right/bottom are exclusive. You can type coordinates instead of dragging. The green outline is your box.

“Save box” stores progress in this tab only. Export JSON before closing and after every few photos. Import your latest exported file to resume. The original photos are never modified.
